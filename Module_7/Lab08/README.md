## Assignment Overview

This assignment focuses on creating and comparing interactive data visualizations using three different web-based technologies: **ESRI Operations Dashboard**, **D3.js**, and **Highcharts**. The objective is to understand how each platform handles data visualization, interactivity, and presentation, while applying appropriate chart types to represent real-world data effectively.

---

## Tasks

## **1. Dashboard**

An ESRI Operations Dashboard was created following the tutorial: How to Create a Simple Real-Time Dashboard [https://community.esri.com/t5/arcgis-dashboards-blog/how-to-create-a-simple-real-time-dashboard/ba-p/888719]. While the data used was fictional or incomplete, this dashboard could be used to see the condition of the streets, status of the snow removal operations, and snow-related complaints that have been reported. 

## **2. D3.js Visualization**

A grouped bar chart was created using **D3.js** to visualize the weekly **high and low temperatures** for College Station. The grouped bar chart format was selected to clearly compare daily temperature ranges.

---

## **3. Highcharts Visualization**

An interactive **line chart** was created using **Highcharts** to visualize the College Station weekly temperature forecast. Two separate data series were plotted to represent **daily high and low temperatures**, allowing temperature trends to be compared across the week.

---

## Output

The following deliverables were produced for this lab:

- One ESRI Operations Dashboard
- One D3.js interactive chart (HTML file)  
- One Highcharts interactive chart (HTML file)
